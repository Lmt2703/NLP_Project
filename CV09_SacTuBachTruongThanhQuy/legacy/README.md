# Thư mục lưu trữ mã nguồn và kết quả thử nghiệm ban đầu (Legacy Archive)

Thư mục này lưu giữ các tệp script và bảng tính nháp trước khi tối ưu hóa pipeline:
- `tien_xu_ly.py`: Script tiền xử lý ban đầu (chưa sửa lỗi ghi đè ký tự VNI).
- `ghep_cap_so_bo.py`: Script ghép cặp sơ bộ ban đầu theo mã đoạn.
- Các tệp `q4_cleaned.txt`, `q7_cleaned.txt`, `q4_ghep_so_bo.xlsx`, `q7_ghep_so_bo.xlsx`: Kết quả nháp ban đầu.

Toàn bộ mã nguồn sản xuất chính thức hiện được chuẩn hóa tại thư mục `src/` và chạy tự động qua `run_pipeline.py`.
